# Plantilla PowerPoint de referencia

Carpeta en GitHub para la plantilla editable del proyecto.

**Nombre esperado:** `07_plantillas/plantilla_master.pptx`

## Subida
Desde GitHub: abre esta carpeta → **Add file → Upload files** → selecciona el archivo `.pptx` → confirma el commit.

A diferencia del libro, una plantilla creada por ti puede guardarse en GitHub si tienes los derechos necesarios. Si contiene imágenes con derechos de terceros o información privada, conviértelo primero en repositorio privado.

## Uso por Codex
Codex deberá abrir este PPTX, analizar proporciones, fuentes, colores, elementos del patrón y composiciones, y utilizarlo como base de las 100 diapositivas sin rasterizar los componentes editables. En ausencia de plantilla, debe seguir `00_configuracion/manual_visual.md` y señalar que el diseño es provisional.

## Entrada
La carpeta `inputs_privados/` contiene el libro (solo en entorno privado); esta carpeta contiene exclusivamente la plantilla PPTX.
