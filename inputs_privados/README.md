# Libro de referencia — carpeta de entrada para Codex

Esta carpeta es el **punto de entrada previsto** para el libro completo:

`inputs_privados/Teoria de Máquinas Salvador Cardona.pdf`

**IMPORTANTE: el repositorio está actualmente PÚBLICO. NO subas aquí el PDF mientras siga público.** Los permisos del repositorio, no `.gitignore`, determinan quién puede descargar un archivo subido mediante la interfaz web de GitHub. `.gitignore` no protege material ya publicado.

Antes de subir el libro:
1. Comprueba que dispones de autorización para almacenar/compartir digitalmente la obra en este entorno.
2. Cambia el repositorio a **Private** en GitHub → Settings → General → Danger Zone → Change repository visibility.
3. Verifica que GitHub indique **Private** en la página del repositorio.
4. En esta carpeta usa **Add file → Upload files** y sube el PDF con el nombre exacto `Teoria de Máquinas Salvador Cardona.pdf`.
5. Conecta Codex a **este repositorio privado** con acceso de lectura; podrá hacer checkout/clonar la versión autorizada.

**Alternativa de mayor protección:** no subir el libro a Git, mantener el PDF privado fuera del repositorio y montarlo manualmente en esa misma ruta del entorno de Codex.

Si se hace privado después de haber subido el libro públicamente, la exposición anterior no se revierte.
